## GitHub concepts used in this assignment
- **Issue**: defines the goal and acceptance criteria for the work before any content is written.
- **Branch**: an isolated line of work (feature/github-ai-workflow) so the default branch stays stable until the work is reviewed.
- **Commit**: a focused, meaningful snapshot of one logical change, with a clear message explaining what and why.
- **Pull request**: a proposal to merge the feature branch into the default branch, including a summary, links, and a checklist for review.
- **Default branch (main)**: the stable, canonical branch that reflects the project's accepted state.
